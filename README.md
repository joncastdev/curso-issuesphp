## Introduction

Curso IssuesPHP Framework Dede Cero en Udemy con proyecto de un CRUD.

## Documentation

Manual del framework [blog/docs](https://issuesphp.blogspot.com/p/issuesphp.html) y [Curso/Completo](https://www.udemy.com/course/issuesphp-desde-cero-un-framework-de-php-ligero/?couponCode=README).


## Setup

- PHP 
- MySQL
- [Composer](https://getcomposer.org/)
- [IssuesPHP Framework](https://github.com/issuesphp/issuesphp)



## Installation

-  Clone Project

```bash
$ git clone https://github.com/joncastdev/curso-issuesphp.git
``` 

```bash
$ composer install
```

```bash
$ php issues.php
```

-  Run Local Server

```bash
$ http://localhost/issuesphpdev/
```

-  Active mod_rewrite apache

```bash
$ sudo a2enmod rewrite
```
